# Dukas


## General

This repo contains data freely avaliable from dukascopy. It's not the greatest but it is free and easily avaliable and so allows others to validate.

TrueFx was a nicer source but they paywalled their history.

I use https://github.com/Leo4815162342/dukascopy-node to download the data.

## Data Oddities

There are Saturdays in this data. A cursory investigations suggests that for almost all of these the values are equal to the close of Friday. The exceptions are some saturdays that lie on new years day (Jan 1st). I haven't terribly concerned myself with it.
